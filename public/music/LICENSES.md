# Hotpot music: sources and licenses

Checked 2026-10-08. All found music is real recordings; nothing here was composed or generated.

## Ready to use (2 tracks)

Files are Wikimedia's own MP3 transcodes of the original Ogg uploads (same recording, same license; MP3 plays in every browser). Both are solo gaohu (the high Cantonese fiddle) playing classic Guangdong music (廣東音樂), no vocals.
They are **CC BY-SA 4.0**, not public domain: free to use in the game, but the credit line below must appear somewhere (credits screen or about page), and if we edit the audio itself (trim, loop, remix), the edited file must stay CC BY-SA 4.0. The game's code is not affected.

## Leads not downloaded (rights unclear)

Genuine 1910s-1930s Cantonese instrumental 78 rpm records exist on the Internet Archive, but none has a confirmed recording date. In the US a recording is only public domain if published before 1926, so these were skipped. If someone can date them to before 1926, they would be true public domain.

| Piece | Record | Where |
|---|---|---|

| Cantonese instrumental, unknown troupe | Victor 42126 | same item, track 17 |
| Cantonese suona instrumental | Tsing Ping 33 | same item, track 15 |
| Lu Wencheng & He Dasha, 雨打芭蕉 | Columbia 49937 (likely 1930s, so probably not US public domain) | same item, track 28 |

The uploader of those compilations gave no license, so the only basis would be the recordings' age.
